# Инструменты отчёта 89

Все скрипты читают и пишут файлы в текущей папке. Кошельки в выводе — полные адреса публичных данных; в отчёт попадают
только префиксы.

| скрипт | что делает |
|---|---|
| `lb_pnl.py` | лидерборд категории crypto (день, неделя, месяц, по 300) → `lb.json`; дневной PnL каждого кошелька по записи биржи (`/v2/user-pnl`) → `upnl.json` |
| `prof7.py [ДНЕЙ]` | итог за N дней по записи биржи: PnL, позиции, ребейты мейкера, награды, комиссии, оборот, сделки, дни в плюсе → `prof7.json` |
| `who7.py` | последние ~2000 сделок 60 лучших кошельков (с ≥ 300 сделок), отдельно как тейкер, плюс activity → `who7_raw.json` |
| `who7_an.py` | профиль: виды рынков, доля исполнений мейкером, цены, размеры, слияния / выкупы |
| `outcomes.py SLUGS.json` | итоги окон из Gamma → `outcomes.json` (кэш) |
| `bn_build.py SYM...` | секундные цены Binance из `bn/*.zip` (data.binance.vision) и `bn/<SYM>-1s-today.csv` → `bn1s.npz` с 10 ноября |
| `bn_today.py SYM` | секундные цены Binance за сегодня (data-api.binance.vision) |
| `fairlib.py` | справедливая цена стороны по Binance (модель Перехватчика, отчёт 83) |
| `taker1.py ПРЕФИКС` | покупки тейкера против справедливой цены: перекос, время в окне, движение Binance, по дням |
| `mkt_mom.py ПАПКА` | все покупки тейкеров BTC 5 мин (данные отчёта 83, 18–21 ноября): доход по «справедливой цене × движению Binance за 60 с»; калибровка модели |
| `maker1.py ПРЕФИКС...` | исполнения мейкера: цена против справедливой, итог окна без ребейта, маркаут 5 и 30 с, движение Binance перед исполнением |
| `mkt_maker.py ПАПКА` | сторона мейкера во всех сделках тейкеров BTC 5 мин: доход на акцию по тому, насколько цена была лучше справедливой |
