# 46. Кто торгует 5-минутками, кто на них зарабатывает и как их обыгрывать (9 ноября 2026)

Данные: все сделки 5-минутных рынков BTC и ETH за сутки (8 ноября ~08:00 → 9 ноября ~08:00 UTC, по 289 окон),
публичный Data API v2 с `taker_only=false`: видны и тейкеры, и мейкеры каждой сделки. BTC: 1.21 млн записей,
7 762 кошелька, 10.8 млн акций. Плюс секундные цены Binance. Скрипты — `reports/46_tools/`.

P&L кошелька в окне = деньги за сделки + акции победившей стороны (продажа считается шортом, это верно и для
«split и продать»), минус комиссия тейкера 0.07·p·(1−p), плюс ребейт мейкера 20 % от неё. Маркаут — цена стороны
через N секунд минус цена сделки, в ¢ на акцию (после конца окна — исход).

## 1. Коротко

- **Деньги текут от тейкеров-игроков к крупным мейкерам.** Игроки теряют по $3–8k в день каждый, крупные мейкеры
  зарабатывают по $2–9k в день. Рынок раздроблен: топ-10 кошельков — 15 % объёма.
- **Мейкер теряет в двух местах:** если Binance за 3 с до исполнения сдвинулся против него (−6¢ на акцию) и если
  его сторона позади страйка (−1…−2¢). Наш мейкер стоял на обеих сторонах и проигрывал быстрым ботам.
- **Самое прибыльное место — последняя минута, мейкером:** заявка на уже решённую сторону по 0.92–0.98 выигрывала
  ~100 % на BTC и ETH, +2…+7¢ на акцию. Брат уже сделал такого бота (LM), здесь — улучшение цены и фильтра (LM2).
- **В этой ветке:** два бумажных бота — LM2 (LM с заявкой ≤ 0.96 и строже фильтром Binance) и G2 (мейкер G, который
  открывает позицию только на фаворите). Тесты: 125 passed.

## 2. Как устроен рынок (BTC, сутки)

- Каждое окно начинает торговаться ещё до старта (1–3 % объёма за минуту до него). Внутри окна объём ровный,
  8–9 % на каждые 30 с, пик в секундах 240–269 (13 %).
- Тейкер платит 0.07·p·(1−p) (1.75¢ при цене 0.5), мейкер получает 20 % от этого назад. Наград за ликвидность на
  5-минутках нет.
- В среднем мейкерские исполнения дают +0.1¢ через 60 с и +0.4¢ к исходу: заработок мейкера — это спред, ребейт и
  выбор, где стоять.

## 4. Когда мейкерское исполнение прибыльно (все мейкеры рынка)

| условие в момент исполнения | BTC: доля объёма | BTC: через 60 с / к исходу | ETH: через 60 с / к исходу |
|---|---:|---:|---:|
| Binance за 3 с **против** мейкера ≥ 1 б.п. | 11 % | **−6.2¢ / −5.7¢** | |
| Binance за 3 с **за** мейкера ≥ 1 б.п. | 9 % | +7.5¢ / +7.2¢ | |
| Binance спокоен | 80 % | +0.1¢ / +0.4¢ | |
| сторона позади страйка > 2 б.п. | 30 % | **−1.2¢ / −0.7¢** | −2.0¢ / −2.8¢ |
| у страйка (±0.5 б.п.) | 16 % | −0.2¢ / 0.0¢ | −1.3¢ / −0.1¢ |
| впереди 2–5 б.п. | 14 % | +1.5¢ / +1.5¢ | +2.0¢ / +1.8¢ |
| впереди > 5 б.п. | 16 % | +1.3¢ / +1.3¢ | +3.3¢ / +2.5¢ |
| впереди + Binance спокоен + цена 0.40–0.60 | 3 % | **+3.9¢ / +2.6¢** | +0.9¢ / +6.1¢ |
| позади + спокоен + цена 0.40–0.60 | 3 % | −1.6¢ / +1.8¢ | −2.8¢ / −4.3¢ |

Выводы:
- **Главный враг мейкера — скорость.** После хода Binance против нас исполнение стоит −6¢ на акцию. Быстрые боты
  видят Binance раньше нас (у нас зеркало с задержкой ~0.1–0.2 с плюс сервер). Любое ускорение реакции на Binance
  стоит денег.
- **Не стоять на стороне, которая позади страйка.** Короткие движения продолжаются (`reports/40_microstructure.md`:
  отношение дисперсий ≈ 1.9), поэтому отстающая сторона чаще продолжает отставать.

## 5. Последняя минута: «замок» тейкером и мейкером

- В половине окон (BTC 48 %, ETH 51 %) кто-то покупает будущего победителя по 0.90–0.98 в последнюю минуту.
  Дешёвые продажи победителя живут медиану **12 с** с секунды 241: это не гонка миллисекунд. Бумажный L сделал 1 вход
  за 8 часов не из-за скорости, а из-за строгих условий; часть окон вообще без продаж (брат: 30 из 61).
- Покупка «в среднем» по 0.90–0.98 не зарабатывает на BTC (тейкеры 95.6 % побед, −0.15¢), но зарабатывает на ETH
  (99.6 %, +3.8¢). Избирательные покупатели BTC выигрывают 99.9–100 % и получают +2…+6¢.
- **Мейкерские заявки на решённую сторону** (Binance впереди ≥ 2 б.п., спокоен, секунды 240–294):

- `strategy.favorite_only` (по умолчанию выключено): открывающая заявка только на стороне с ценой ≥ 0.5 + значение.
  Закрывающие заявки не ограничены.
- `pmbot-5m-g2` = `config/g2.toml`: G + `favorite_only = 0.02`. Сравнение с G по маркауту-60 и P&L.
- `pmbot-lock-maker2` = `config/lock_maker2.toml`: LM с `a_max = 0.96` и `adv3_bp = 1.0`, остальное как у LM (тест
  проверяет). Сравнение с LM.
- Юниты, Telegram-подписи, списки в `autoupdate.sh` / `install_units.sh`, тесты (125 passed).

## 8. Ограничения

- По одним суткам на актив. «~100 % побед» — это 30–65 окон в сутки на клетку: истинная доля может быть и 95 %.
  При цене 0.96 один проигрыш (−$4.8 на 5 акций) съедает ~20 выигрышей.
- «Впереди страйка» считается по Binance относительно цены Binance в начале окна, а не по Chainlink. Бот считает
  точнее (`pmbot/lockmodel.py`).
- Чужие исполнения в среднем ≠ наши: мы медленнее большинства мейкеров, поэтому плохих исполнений у нас будет
  больше среднего. Решает paper с моделью очереди, а потом live на минимуме.
- Кошелёк ≠ человек: у одного игрока может быть много кошельков.
