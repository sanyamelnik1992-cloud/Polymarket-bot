# Инструменты отчёта 78 (погода)

Запускать из отдельной рабочей папки; файлы пишутся туда же. Источники публичные: Gamma, data-api, IEM ASOS
(архив METAR), aviationweather.gov (станции), Open-Meteo (прогнозы; у previous-runs суточная квота на IP).

1. `collect_events.py 2026-11-03 2026-11-16` — события «Highest temperature in CITY on DATE»: корзины, победитель, станция.
2. `collect_wx.py 2026 11 1 2026 11 17` — станции, наблюдения, прогнозы. Наблюдения всех типов (`obs_all.json`) и минуты
   регулярных сводок станции (`routine_min`) — см. отчёт 78, раздел 2 (в отчёте — как получены).
3. `collect_trades.py` — все сделки по рынку во всех корзинах закрытых событий.
4. `build_days.py` — день каждой станции: сводки по местному часу, итоговый максимум, победитель (проверка правил).
5. `calib.py` — насколько точны цены всего рынка: результат покупок по цене и по часам до конца дня.
6. `endgame.py` — конец дня: как часто побеждает корзина текущего максимума и по каким ценам её покупали.
7. `backtest_obs.py` — модель «только наблюдения» (без прогноза) против сделок рынка, без заглядывания вперёд.
`wxlib.py` — правила рынка (то же, что `pmbot/weather/rules.py`).
