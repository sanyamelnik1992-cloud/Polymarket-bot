# Инструменты отчёта 80

Только публичные данные: сделки (`data-api.polymarket.com/v2/trades`), итоги окон (Gamma), секундные цены Binance
(`data.binance.vision`, архив; `api.binance.com` из песочницы закрыт по стране). Адресов кошельков в репозитории нет:
кошелёк конкурента находится шагом 2 и передаётся в шаг 3 префиксом в командной строке. Скрипты читают и пишут файлы
в текущей папке; запускать из отдельной рабочей папки, скопировав туда скрипты.

| шаг | что | команды |
|---|---|---|
| 1 | Кандидаты: кто покупает фаворита по ≥ 0.95 в конце окна по $30–250 | `../77_tools/mkt_map.py` → `cands.py mkt_taker.json` → `cands.json` |
| 2 | Сделки кандидатов с 8 ноября и сверка дней со скрином (разные часовые пояса) | `fetch.py cands.json 1794139200 40 trades_c9.json` → `match2.py trades_c9.json` |
| 3 | Его сделки с итогами окон, таблица как на скрине, профиль входов | `one.py trades_c9.json ПРЕФИКС comp.json` → `an.py comp.json 3` → `prof.py` (→ `comp_entries.json`) |
| 4 | Секундные цены Binance 8–16 ноября | zip-архивы `{BTC,ETH,SOL,XRP}USDT-1s-2026-11-DD.zip` в `./bn` → `python3 -I bn_load.py bn bn1s.npz` |
| 5 | Итоги всех 13 056 окон 5 мин / 15 мин / час 9–16 ноября | `outcomes.py` → `windows.json` |
| 6 | Его входы в наших терминах (отрыв, z) и сколько проигрышей «положено» | `comp_z.py`, `expect.py` |
| 7 | Проигрыш лидера по z и времени до конца, без цен | `bt.py`, `bt2.py ПОЛ_СИГМЫ ОКНО_С` (`bt2.py 0 3600` — сигма за час), `losers.py` |
| 8 | Публичные сделки последних минут всех окон (~10 мин в 16 потоков) | `mtrades.py` → `mtrades.json` |
| 9 | Повтор правил на сделках рынка | `sim.py 15m '[{"z0":3,"x_hi":300,"x_lo":120,"cap":0.99,"pmin":0.985}]'`, `stab.py`, `sens.py`, `combo.py` |
| 10 | Где продавцы по 0.99: ранняя зона против последней минуты | `sellers.py` |
| 11 | Сигма из 10-секундных движений (как в боте): пороги и правило бумажных ботов по дням | `combo10.py 10`, `combo_bot.py` (`zmod.STEP = 10`) |

`zmod.py` — общие функции: цена Binance в секунду, страйк окна (среднее Binance за [T−62, T−3], у часовых — цена на начало
часа), отрыв, сигма (корень из среднего квадрата секундных доходностей за 300 с или за час; при `STEP = 10` — 10-секундных, делённый на √10, как считает бот), τ (секунды до начала
закрывающего TWAP + 20; у часовых — до конца), z = отрыв / (сигма · √τ). `mcal.py` — калибровка покупок по 0.98–0.99 на
выборке отчёта 77.

Модель исполнения в `sim.py`: первая секунда t в зоне, где z ≥ порога и в [t, t + 5 с] была публичная покупка лидера по
цене в [`pmin`, `cap`]; вход по цене этой сделки, один на окно. Комиссия 0.07·p·(1−p) на акцию.
