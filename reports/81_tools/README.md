# Инструменты отчёта 81

Только публичные данные и наши записи; адресов кошельков нет. Скрипты читают и пишут файлы в текущей папке.

| шаг | что | команды |
|---|---|---|
| 1 | Итоги Gamma и публичные сделки конца окна, все окна 5 / 15 мин 1–17 ноября (~25 мин) | `get_data.py` → `windows_all.json`, `mtrades_all.json` |
| 2 | Секундные цены Binance 31 октября – 16 ноября (архив `data.binance.vision`, скачивать с сервера) | `bn_load_all.py bn bn1s_all.npz` |
| 3 | Правило отчёта 80 на 1–8 и 9–16 ноября; 16 дней вместе, монеты, просадка | `sim_all.py`, `sim16.py` |
| 4 | То же на стаканах рекордера (Chainlink, покупка по стакану через 0.3 с) | `early_books.py windows_all.json ТЕЙП...` (→ `early_books_res.json`), `early_steps.py windows_all.json OUT.parquet ТЕЙП...` → `eval_steps.py OUT.parquet` |
| 5 | Выход при развороте против «держать» | `stops.py early_books_res.json` |
| 6 | Реальные деньги по ступеням (на сервере, в `data/`) | `live_tiers.py` |
| — | Архив журналов остановленных ботов (сервер, root) | `archive_journals.sh` |

Тейпы — выгрузки `reports/51_tools/extract_day.py ... 120 300` (стаканы с 120-й секунды окна) + Chainlink / Binance
рекордера: `r1107`, `r1108`, `r1109`, `d1109` (7–9 ноября), `d1117` (16–17 ноября).
